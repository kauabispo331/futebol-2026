# Futebol 2026 — Simulador

Jogo de simulação de futebol feito em HTML, CSS e JavaScript puro.

## Modos

- **Amistoso:** partidas jogáveis lance a lance, com dificuldade, clima, comentários, posse de bola, gols, finalizações, faltas e substituição.
- **Editar — Beta:** personalize nome, escudo, cor, força geral e jogadores dos times. Os dados ficam salvos no navegador.

## Como jogar

Abra `index.html` no navegador.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` e este `README.md`.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o link do GitHub Pages.

O jogo não precisa de servidor, banco de dados ou dependências externas.
